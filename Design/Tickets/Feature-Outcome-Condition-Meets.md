# Outcome Condition Meets

Status: untriaged
Filed: 2026-08-27

The format has no way to write a meet that states a condition on the result rather than a position —
"cut so these edges are equal length." It is solvable, but there is no point to name, so the existing
vertex, fraction and TCP forms cannot express it. Recorded in `Design/design-authoring-format.md` as
one of the two cases the format is known not to stretch to, and parked waiting on a real design that
needs it.
